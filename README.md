# arduino-projetos

Códigos de Arduino que fui fazendo nas aulas e em casa.

| Pasta | O que faz |
|-------|----------|
| [`01-servo-potenciometro`](01-servo-potenciometro) | Servo controlado por potenciômetro |
| [`02-sensor-luz`](02-sensor-luz) | Sensor de luz digital |
| [`03-sensor-noite-dia-lcd`](03-sensor-noite-dia-lcd) | Mostra "Dia" ou "Noite" no LCD |
| [`04-dht11-lcd`](04-dht11-lcd) | Temperatura e umidade no display |
| [`05-motor-dc-potenciometro`](05-motor-dc-potenciometro) | Motor DC com controle de direção e velocidade |
| [`06-bluetooth-leds`](06-bluetooth-leds) | Controla 2 LEDs pelo celular via Bluetooth |
| [`07-bluetooth-leds-temp`](07-bluetooth-leds-temp) | LEDs via Bluetooth + sensor de temperatura |
| [`08-bluetooth-4leds-pwm`](08-bluetooth-4leds-pwm) | 4 LEDs com toggle |
| [`09-dht11-lcd-v2`](09-dht11-lcd-v2) | Outra versão do DHT11 com LCD |

LCD I2C costuma ser no endereço `0x27`. Se não aparecer nada, tenta `0x3F`.
